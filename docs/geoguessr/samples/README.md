# GeoGuessr samples

Captured API/WebSocket data, client-source excerpts, screenshots and test scripts supporting the [GeoGuessr documentation](../README.md).

- Root JSON files: party discovery, game-server snapshots, event sequences and control probes. Filenames identify the event or scenario.
- [game-master-flow/](game-master-flow/): manual preview, live/result and next-preview screenshots/state snapshots, plus final-scene source.
- [scoring-animation/](scoring-animation/): comparison frames, scoring/audio source excerpts and cue maps.
- [map-style/](map-style/): map factory, CSS and live rendering options.
- [automation/](automation/): the isolated guest test-player script.

Interpretation and implementation guidance belong in the parent documentation directory. READMEs here describe the sample files and their capture limitations.
